# Guia de Contribuição - PortfolioHUB

Este documento orienta o fluxo de trabalho para o desenvolvimento e atualização do PortfolioHUB.

## Fluxo de Trabalho (GitFlow Adaptado)
1. Nunca faça commits diretamente na branch `main`.
2. Crie uma branch para a sua alteração: `git checkout -b feature/sua-feature`.
3. Faça os commits seguindo o padrão de Commits Semânticos (ex: `feat: adiciona nova seção`).
4. Abra um **Pull Request** para a branch `main` e aguarde a validação de segurança.
